## Dynamic tabs in rmarkdown

Working with different aspects of RMarkdown files provides a magnatidue of exciting little hacks and work arounds. One of the nicest little snippit of code is `.tabset` allows for dynamic tabs that can look like buttons by using `.tabpills`. 

This is added at the end of a `header` and the tabs are started at each of the headers one level below until the next header of a different level.

Website with demo and template [here](https://github.com/davan690/dynamicTabsRmarkdown/).

Clone the repo from [https://github.com/davan690/dynamicTabsRmarkdown.git](https://github.com/davan690/dynamicTabsRmarkdown.git)
