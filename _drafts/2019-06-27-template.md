Markdown content for blog posts uses templates from within the project. Jekyll websites use `yaml` headers to contain the metadata needed to generate the formated posts. The basic metadata is as follows:

```
---
title: ""
layout: post
subtitle: ""
image: /img/...
permlink: /first-post.html
tags: ["website", "overview", "general"]
bigimg: /img/...
use-site-title: true
---
```
