# 极简艺术昼夜切换开关（暗黑模式）设计规范

日期：2026-04-26

## 1. 概述与目标 (Overview)
在当前基于 `beautiful-jekyll` 的博客主页顶部导航栏（Navbar）右侧，新增一个极简风格、带有平滑变形动画的“昼夜切换开关”（Dark Mode Toggle）。这旨在为博客增加“状态式交互”和趣味性，同时保持整体设计的艺术感与干净排版。

## 2. 界面与交互设计 (UI & UX)
- **位置**：顶部导航栏（Navbar）最右侧，与现有菜单项（Blog, Resources, About Me）或图标平齐对齐。
- **视觉形态**：
  - **默认（白天）**：极简线条风格的太阳图标。
  - **切换时（动画）**：纯 CSS 驱动的 SVG 变形动画。太阳的光芒线条（Rays）缩回/渐隐，中心圆环通过 SVG Mask 或 `clip-path` 变形为一个月牙（Moon）形状，并伴随约 15-30 度的轻微自转。
  - **背景过渡**：网页背景色、导航栏背景、卡片背景及字体颜色在切换时，应用 `transition: background-color 0.3s ease, color 0.3s ease;` 实现丝滑的明暗淡入淡出，避免生硬闪烁。
- **色彩调色板 (Color Palette)**：
  - **白天（沿用现有）**：背景 `#FFFFFF`，文字 `#404040`，链接 `#008AFF`。
  - **黑夜（新增变量）**：主背景 `#121212`，导航栏/页脚/代码块等次背景 `#1E1E1E`，主要文字 `#E0E0E0`，次要文字 `#A0A0A0`。

## 3. 架构与状态管理 (Architecture & State)
- **HTML 注入点**：修改 `_includes/nav.html`（或相应的主题导航栏组件文件），插入包含 SVG 和交互按钮的 HTML 结构。
- **CSS 注入点**：创建一个专门的暗黑模式样式文件（例如 `assets/css/dark-mode.css`），或在现有全局 CSS 文件末尾追加样式。通过在 `<body>` 标签上切换 `.dark-mode` 类来控制全局样式变量生效。
- **JS 逻辑层 (State Management)**：
  - 创建一个专门的交互脚本（如 `assets/js/dark-mode.js`）。
  - **初次访问检测**：利用 `window.matchMedia('(prefers-color-scheme: dark)')` 检测操作系统默认偏好。
  - **偏好持久化**：每次点击切换时，将当前状态（`light` 或 `dark`）保存至浏览器的 `localStorage`。
  - **加载闪烁预防 (FOUC)**：确保 JS 状态检查在页面渲染早期执行（最好在 `<head>` 中或 `<body>` 顶部），以防止由于状态延迟加载导致页面先白后黑的闪烁问题。

## 4. 验收标准 (Acceptance Criteria)
1. 导航栏右侧出现太阳/月亮切换按钮，且不破坏现有的响应式布局（移动端下也需合理折叠或居中显示）。
2. 点击按钮时，SVG 动画平滑流畅，网页颜色切换带有 0.3s 的淡入效果。
3. 切换到黑夜模式后，刷新页面或跳转至其他文章，黑夜模式状态依然保留（利用 `localStorage` 成功记忆）。
4. 代码符合现有 Jekyll 项目规范，不引入外部庞大依赖库（仅使用原生 JS、CSS 和内联 SVG）。

## 5. 未决项/风险 (Risks)
- 在注入动画图标时，需要确保移动端汉堡菜单（Hamburger Menu）展开时的布局不被挤乱。
- 原有的代码高亮（Pygment/Rouge）可能在暗黑模式下对比度不足，需要针对代码块 `.highlight` 追加暗色系样式覆盖。
