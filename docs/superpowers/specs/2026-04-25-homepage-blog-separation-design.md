# 架构设计方案：首页与博客内容分离 (Homepage & Blog Separation)

日期：2026-04-25
主题：将当前以博客文章为主的首页改造为独立主页，并将文章列表迁移至 `/blog/` 目录。

## 背景与目标

当前站点的根路径 (`/`) 使用了 Beautiful Jekyll 的 `layout: home`，直接作为博客文章的聚合展示页。为了提供更清爽的个人介绍展示，需要将首页（Homepage）与博客（Blog）进行物理分离：
- `/`：作为纯粹的个人欢迎页和展示页。
- `/blog/`：作为新的博客聚合页，展示所有的文章流（Posts）。

## 系统设计与组件

### 1. 首页重构 (`index.html`)

将现有的根目录 `index.html` 改造为标准的页面布局：
- **布局类型 (Layout)**：由 `home` 更改为 `page` 或 `default`，移除文章列表的渲染逻辑。
- **页面内容**：保留现有的动态标语（Hitokoto.js，目前加载在副标题位置）。添加一段简短的个人欢迎语，提供一个空白的画板供未来编辑个人介绍。
- **影响**：根路径将不再输出任何 `_posts/` 中的内容。

### 2. 博客聚合页 (`blog/index.html`)

在根目录下创建新的 `blog` 目录，并在其中创建 `index.html`：
- **布局类型 (Layout)**：设置为 `home`，这将使其接管 Beautiful Jekyll 的文章列表渲染。
- **标题与副标题**：可以设定为 "Blog" 或 "我的文章"，副标题可自定义或留空。
- **影响**：访问 `/blog/` 将展示原先在首页展示的文章摘要流。

### 3. 分页器适配配置 (`_config.yml`)

因为文章列表从根目录移动到了 `/blog/` 目录下，Jekyll 默认的分页路径生成规则（如 `/page2/`）将会导致 404 错误。需要修改全局配置以适应新的目录结构：
- **配置项**：在 `_config.yml` 中添加 `paginate_path: "/blog/page:num/"`。
- **预期行为**：确保第二页以后的博客流路径为 `/blog/page2/`，保证分页组件正常工作。

### 4. 导航菜单更新 (`_config.yml`)

- **配置项**：在 `navbar-links` 中添加 `Blog: "blog"` 键值对，使访客可以从顶部导航栏无缝切换到博客聚合页。*(注：用户已提前完成此项更改)*

## 测试与验证标准

1.  **首页访问**：访问 `sukaijun.dpdns.org/` 时，页面不包含任何文章列表，且动态标语正常加载。
2.  **博客页访问**：访问 `sukaijun.dpdns.org/blog/` 时，页面展示带有分页的文章列表。
3.  **分页测试**：在 `/blog/` 页面点击分页按钮（如“Older Posts”），能够成功跳转至 `/blog/page2/`，且内容正确加载。
4.  **构建检查**：执行 `bundle exec appraisal jekyll build --future --config _config_ci.yml,_config.yml` 必须无警告和错误。

## 后续演进

完成此架构变更后，可以自由在 `index.html` 中添加基于 Markdown 的复杂个人介绍排版，而无需担心影响博客的结构。
